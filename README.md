# Счётчик калорий

Простое Android-приложение для подсчёта калорий:

- дневная цель (по умолчанию 2000 ккал, меняется нажатием на «Цель»);
- добавление еды через поиск по своей базе продуктов: начните вводить
  название внизу экрана, выберите продукт, укажите вес порции —
  калории и БЖУ посчитаются сами;
- подсчёт БЖУ: белки, жиры и углеводы за день и по каждой записи;
- своя база продуктов (КБЖУ на 100 г), редактируется на отдельном экране;
- ручной ввод записи с БЖУ: пункт «Ввести вручную» в меню кнопки «книжка»;
- экспорт и импорт всех данных в JSON-файл (меню «⋮» вверху) — резервная
  копия переживает переустановку приложения;
- сканер штрих-кодов (вертикальный, с фонариком): первый скан кода
  ищет продукт в общей базе, повторный скан сразу находит его в вашей;
- общая база продуктов [Open Food Facts](https://ru.openfoodfacts.org)
  (есть российские товары): неизвестный штрих-код автоматически ищется
  в ней, а по названию можно искать через «🌐 Найти в общей базе»;
- проверка обновлений: приложение раз в сутки сверяется со страницей
  Releases и предлагает скачать новую версию (или вручную:
  меню «⋮ → Проверить обновления»);
- частые продукты показываются в подсказках первыми;
- статистика за 7 или 30 дней: график калорий с линией цели,
  график БЖУ по дням, средние значения (меню «⋮»);
- дневник веса (меню «⋮ → Вес и параметры»): текущий и целевой вес,
  плавный график динамики с линией цели, история записей;
- расчёт дневных КБЖУ по формуле Миффлина-Сан Жеора: задайте пол,
  возраст, рост и уровень активности — приложение посчитает калории
  и БЖУ для набора мышечной массы, поддержания или похудения
  и установит их как дневные цели в один тап;
- цели не только по калориям, но и по БЖУ (нажмите «Цель»);
- ежедневное напоминание записать еду (меню «⋮ → Напоминание»);
- виджет на рабочий стол: калории и БЖУ за сегодня;
- прогресс дня — кольцевые диаграммы: большое кольцо калорий и три
  кольца БЖУ, каждое заполняется к своей цели (превышение подсвечивается
  красным);
- боковое меню (кнопка ☰ или свайп от левого края): статистика, вес,
  база продуктов, напоминание, экспорт/импорт, обновления;
- история по дням (стрелки ‹ › вверху экрана);
- редактирование записи — нажатие, удаление — долгое нажатие;
- все данные хранятся локально на телефоне
  (SharedPreferences: `/data/data/com.dyra.calories/shared_prefs/calories.xml`);
  интернет нужен только для общей базы продуктов и проверки обновлений —
  всё остальное работает офлайн.

Минимальная версия Android — 8.0 (API 26).

## Как получить APK

### Способ 0 — страница Releases (проще всего)

Готовые APK лежат на странице
[Releases](https://github.com/dyra4eck/calories/releases) — скачиваются
в один тап прямо с телефона, без логина на GitHub. Новый релиз
публикуется автоматически при пуше тега `v*` (например, `v1.4`).

### Способ 1 — GitHub Actions (без установки чего-либо)

В репозитории настроена автоматическая сборка (`.github/workflows/build-apk.yml`).
При каждом пуше GitHub сам собирает APK:

1. Откройте вкладку **Actions** в репозитории на GitHub.
2. Выберите последний запуск **Build APK** (зелёная галочка).
3. Внизу страницы, в разделе **Artifacts**, скачайте `calorie-counter-apk`.
4. Распакуйте zip — внутри `app-debug.apk`.
5. Перекиньте APK на телефон и откройте его. Android спросит разрешение
   на установку из неизвестных источников — разрешите.

Запустить сборку вручную: **Actions → Build APK → Run workflow**.

#### Подписанный release-APK

Если в репозитории заданы секреты (**Settings → Secrets and variables →
Actions**):

- `KEYSTORE_BASE64` — файл ключа `release.keystore` в base64;
- `KEYSTORE_PASSWORD` — пароль хранилища и ключа (alias — `calories`);

то CI дополнительно собирает подписанный `app-release.apk`
(артефакт `calorie-counter-release-apk`). Без секретов собирается
только debug-версия. Файл ключа храните в надёжном месте: при его
утере обновления поверх установленной release-версии станут
невозможны (потребуется переустановка).

### Способ 2 — Android Studio

1. Установите [Android Studio](https://developer.android.com/studio).
2. **File → Open** — выберите папку проекта.
3. Дождитесь окончания синхронизации Gradle (первый раз качает зависимости).
4. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
5. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

### Способ 3 — командная строка

Нужны JDK 17+ и Android SDK (переменная `ANDROID_HOME` или файл
`local.properties` со строкой `sdk.dir=/путь/к/sdk`):

```bash
./gradlew assembleDebug        # Linux/macOS
gradlew.bat assembleDebug      # Windows
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Структура проекта

```
app/src/main/java/com/dyra/calories/
  MainActivity.kt     — главный экран: записи дня, итоги, выбор продукта, скан
  ProductsActivity.kt — база продуктов: добавление, изменение, удаление, скан
  StatsActivity.kt    — статистика за неделю
  WeekChartView.kt    — график калорий по дням (Canvas, без библиотек)
  ProductDialog.kt    — общий диалог создания/редактирования продукта
  Store.kt            — хранение записей, цели и продуктов (SharedPreferences + JSON)
  Entry.kt            — модель записи (название, ккал, БЖУ, время)
  Product.kt          — модель продукта (КБЖУ на 100 г, штрих-код) и хелперы
  EntryAdapter.kt     — список записей (RecyclerView)
  ProductAdapter.kt   — список продуктов (RecyclerView)
app/src/main/res/     — макеты, строки (русские), тема, иконка
```
